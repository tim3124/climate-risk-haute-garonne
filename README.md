# Climate Risk - Haute-Garonne

Projet SIG complet visant à modéliser le risque climatique
à l'échelle du département de la Haute-Garonne.

## Objectifs

- Calcul d'indicateurs d'aléas climatiques
- Modélisation exposition / vulnérabilité
- Matrice de risque 5x5
- Base de données PostGIS
- Diffusion interactive

## Stack technique

- Python
- PostgreSQL / PostGIS
- QGIS
- Linux / Bash
- Git
